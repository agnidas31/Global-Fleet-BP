Different scope

2The approach

A common model, definitions made explicit, validation built in

Rather than force one artificial definition, every regional definition was documented and every comparison made like for like.

Ingest

Monthly extracts from each region's fleet system.

Standardise

One common data model, with unit and currency carried as columns.

Calculate

KPIs per region, each using that region's documented definition.

Compare

Cross-region views use trends and year-on-year change, not raw totals.

Validate

Reconcile every refresh against each region's own reporting.

Report

Global summary, regional drill-down, definitions and validation pages.
